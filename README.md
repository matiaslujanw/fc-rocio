# Regalo de cumpleaños para Rocío

Experiencia web interactiva con cuatro momentos:

1. Portada de cumpleaños.
2. Corazón con diez toques y frases progresivas.
3. Foto tipo Polaroid y sobre interactivo.
4. Carta final con confeti.

No requiere instalar dependencias. Se puede abrir `index.html` directamente o levantar un servidor local desde esta carpeta:

```bash
python3 -m http.server 4173
```

Luego visitar `http://localhost:4173`.

La foto utilizada está en `public/foto-real.jpeg`.
